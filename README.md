# Душеловка

Маленькая браузерная аркада про демоницу, которая ловит чужие души и уворачивается от проклятых черепов.

Одна HTML-страница, без сборки и зависимостей: чистые Canvas, CSS и JavaScript. Работает мышью, пальцем и с клавиатуры.

![Превью игры](assets/og.png)

## Как играть

- Двигайте демоницу мышью, пальцем или клавишами `←` / `→` (можно `A` / `D`).
- Ловите синие души: каждая серия повышает множитель — до `×5`.
- Не касайтесь красных черепов. Три сердца — три ошибки.
- Розовые сердца восстанавливают жизнь, а на полном здоровье дают бонусные очки.
- Каждые 24 секунды начинается новая волна: предметы падают чаще и быстрее.
- `P` или `Esc` — пауза. `Space` / `Enter` — начать или продолжить.
- Рекорд хранится в `localStorage` браузера.

## Локальный запуск

Из корня проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

Можно открыть и просто через `index.html`, но локальный сервер лучше: так браузер гарантированно загрузит шрифты и спрайт.

[`pages.yml`](.github/workflows/pages.yml) собирает статическую папку `_site` и выкладывает её на GitHub Pages.

## Технические детали

- Игровое поле масштабируется под экран и учитывает `devicePixelRatio`.
- Спрайты и эффекты рисуются на Canvas с `image-rendering`-дружественным масштабированием.
- Звук синтезируется через Web Audio API, без внешних аудиофайлов.
- Учитывается `prefers-reduced-motion`.
- Внешних запросов и аналитики нет: всё работает офлайн после загрузки.

Арт — исходный спрайт, предоставленный автором проекта. Код игры написан для этого репозитория.
